# 00 · Governance — agent rules

- **Owner:** Owners
- **Writes here:** the owner only. Others ask through `HANDOFF_<from>_to_<to>.md` placed in this folder and mark their ticket `blocked_by`.
- **Read before working:** `/CLAUDE.md`, `/AGENTS.md`, `05_LIVE_CONTEXT/05.00_READ_FIRST.md`, this file, then only the files the ticket lists by ID.

## Conventions

- Only the Owners approve files here; agents write proposals in `00.04_Decisions_ADR/PROPOSALS/`.
- ADRs are numbered `ADR-####_Title.md`, never renumbered, superseded by a new ADR instead of edited.

## Quality checklist

- [ ] Decision has context, options, decision, consequences.
- [ ] Index and affected `_AGENT.md` files updated.
