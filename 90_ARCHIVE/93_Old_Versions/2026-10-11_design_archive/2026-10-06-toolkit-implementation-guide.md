# Toolkit implementation guide — Heartweaver and The Veil (Deceiver)

Everything still to implement by hand in the BG3 Toolkit, and what is already in the files. Written
2026-10-06. Sources of truth: `Design/Rework/specs/2026-10-06-heartweaver-design.md`,
`Design/Rework/specs/2026-10-06-deceiver-veil-design.md`, and the prepared files in `Design/Rework/deceiver/`.

**How to read the stats blocks below.** Every "NEW" block is a complete entry as it appears in the game's
`.txt` files: create it in the Stats editor with the same name, type and fields. Text in `"quotes"` replaces a
`{{KEY}}`: it is a NEW localisation string — create a handle with that English text and put the handle in
the field. Text marked `(existing handle hXXXX)` already exists: reuse that handle. UUIDs for new Toolkit
objects (lists, progression rows, class descriptions) are generated by the Toolkit — none are invented here.

**Order of work:** Part 0 (check what is there) → Part 1 (Deceiver, prepared) → Part 2 (Deceiver, still to
author) → Part 3 (Heartweaver subclass) → Part 4 (texts, docs, patch notes).
