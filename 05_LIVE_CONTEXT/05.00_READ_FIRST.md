# 05.00 · READ FIRST — the Arcana mod today

**Arcana Class** is a custom class for Baldur's Gate 3 (final patch 8). Published version **3.1.0.28**
(mod.io, Nexus Mods); a **rework** is in progress and ships as **4.0.0.x** (ADR-0004). The Arcana is a
seer chosen by **Mystra**; each subclass is a tarot Major Arcanum that **awakens its Aspect** in combat.
It casts with **Intelligence** and **Woven Spell Slots** (`ArcanaSpellSlot`); the PC edition (Script
Extender) turns combat into a **deck builder** paid with **Threads** (`ArcanaThread`). The console edition
has no Script Extender. Core = levels 1–12; 13–20 is a later expansion module.
