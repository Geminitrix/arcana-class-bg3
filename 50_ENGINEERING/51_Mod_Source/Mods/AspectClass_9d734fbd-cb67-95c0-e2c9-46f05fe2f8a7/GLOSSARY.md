# AspectClass Mod - Translation Glossary

Internal reference for translating this mods localization. NOT a shipped file - keep it out of `Localization\` so it never gets packed. Regenerate or extend as the mod grows; see the process notes at the bottom.

Languages: PT-BR = BrazilianPortuguese, ZH-CN = Chinese, ZH-TW = ChineseTraditional, FR = French, DE = German, IT = Italian, JA = Japanese, KO = Korean, ES-LA = LatinSpanish, PL = Polish, RU = Russian, ES = Spanish, TR = Turkish, UK = Ukrainian

`PENDING` means this mod-original term was added to English after the last translation sync for that language and has no translation yet - a ready-made gap list for the next sync round.

## 1. Vanilla D and D / BG3 terms this mod references

These are real spell, feature or creature-type names from the base game that this mods flavour text names or reuses. Always use Larians own official translation below rather than inventing one - prior localization audits of this mod found several cases of an invented-but-wrong term replacing the real in-game name, which breaks the link between visible text and what an LSTag Tooltip reference actually points to.

Rows marked [WARN] are short or generic English words with a coincidental exact-text match to unrelated vanilla content (example: the Mimic monster, not this mods "Mimic:" spell-copy prefix) - verify the context matches this mods usage before reusing that translation; do not apply blindly.

## How this was built and how to regenerate it

1. Extract all content entries from Localization/English/english.xml. Short (45 characters or fewer), sentence-less strings (no terminal period, no [N] placeholder, no LSTag) are treated as name-like: spell, ability and status names rather than full descriptions.
2. Extract the official English.pak (Data/Localization/English.pak in the Steam install) via Divine.exe (extract-package then convert-loca), stream it with a System.Xml.XmlReader (never load the roughly 230k-entry file as a DOM), and exact-text-match each name-like string against it. A match means the mod is naming real vanilla content.
3. For vanilla matches, fetch the same contentuids text from each official language pak under C:\Projetos\BG3 Modding\Base Game BG3\Localization\<Lang>\<Lang>.pak using the same extract, convert and stream approach.
4. For everything else (mod-original), look up the existing translation for that same English texts contentuid directly in this mods own Localization\<Lang>\<lang>.xml files.
5. Re-run this whenever new name-like terms show up in English and you want them added - the official pak paths and the exclusion pattern for debug labels are the only two things likely to need updating over time.
